<objective>
Service-layer hardening for the usage-history persistence pipeline. Three deliverables, one wave:

1. Extend `IUsageHistoryService` with `Task SaveHistoryAsync(UsageHistory)` and `UsageHistory? PeekLastSnapshot()` (D-06, D-04).
2. Implement `SaveHistoryAsync` in `UsageHistoryService` using `File.WriteAllTextAsync` and the existing static `JsonOptions` (D-07). Add `SemaphoreSlim _writeLock = new(1, 1)` and serialize ALL writes through it (D-05). Add `_lastSavedSnapshot` field, updated AFTER each successful write (D-04). `ClearHistory` nulls the snapshot BEFORE deleting the file (D-13).
3. Extend `UsageHistoryServiceTests` with 9 new xUnit tests covering HIST-02 (async round-trip), HIST-03 (sync/async byte-identity), HIST-04 (window-reset persists), HIST-05 (first-poll guard via `IsWindowReset(null, x)`), snapshot lifecycle, concurrency safety, and write-failure cache invariant.

Purpose: Decouple poll-cycle disk I/O from the UI thread without breaking the existing JSON contract; enable the termination hook in Plan 21-02 to flush in-memory history without resurrecting a transient ViewModel.

Output: Service contract + impl + 9 new passing unit tests. Plan 21-02 consumes these new interface members.
</objective>
