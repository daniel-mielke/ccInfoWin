<objective>
Close the major UAT gap reported in 21-UAT.md Test 2: the Settings → Abmelden button leaves
`%LOCALAPPDATA%\CCInfoWindows\usage-history.json` on disk because `SettingsViewModel.Logout`
duplicates a stripped-down logout sequence that omits `IUsageHistoryService.ClearHistory()`.
This violates D-13's snapshot-ordering contract (`_lastSavedSnapshot = null` BEFORE
`File.Delete`) on the only logout path the user actually clicks.

Refactor along Option B from the UAT: introduce a parameterless `LogoutRequestedMessage`,
make `SettingsViewModel.Logout` a single-line publisher, and route to the full
`MainViewModel.Logout()` body via `IRecipient<LogoutRequestedMessage>`. This eliminates the
duplicated state-cleanup logic and prevents future drift — there is one logout sequence,
in one place, and every UI surface routes through it.

Purpose: D-13 is honored on every logout path; usage-history.json never leaks across user
sessions on a shared machine.
Output: 1 new message file, 2 ViewModel refactors, 1 round-trip xUnit test, all green.
</objective>
