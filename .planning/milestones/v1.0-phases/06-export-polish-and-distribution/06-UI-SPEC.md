### B. Update Available InfoBar (UPDT-01, UPDT-02, UPDT-03)

Located in MainView Row 0 (stacked with existing "Session Expired" InfoBar).

```
┌──────────────────────────────────────────────────────────────┐
│  ℹ  Update v1.2.0 verfügbar                     [Download] X │
└──────────────────────────────────────────────────────────────┘
```

| Property | Value |
|----------|-------|
| Control | WinUI 3 `InfoBar` |
| Severity | `Informational` (system blue — do not override) |
| Title | "" (empty — message carries full context) |
| Message | "Update v{version} verfügbar" — ViewModel binding |
| IsOpen binding | `ViewModel.IsUpdateAvailable` (OneWay) |
| IsClosable | `true` |
| Closing event | Captures dismissed version → saves to AppSettings.DismissedUpdateVersion |
| ActionButton label | "Download" |
| ActionButton command | `OpenUpdateDownloadCommand` — opens `https://github.com/daniel-mielke/ccInfoWin/releases` in default browser via `Process.Start` |
| Margin bottom | 12px (matches existing Session Expired InfoBar Margin="0,0,0,12") |
| Stack order | Below Session Expired InfoBar in Row 0 (Session Expired shown first when both visible) |
| AutomationProperties.Name on ActionButton | "Update herunterladen" (DE) / "Download update" (EN) |

**Dismiss behavior:** Banner for a given version is suppressed after the user clicks X. `AppSettings.DismissedUpdateVersion` stores the dismissed version string. Banner reappears only when a newer version is detected on next hourly check.

### D. Export PNG Composition Layout

The exported PNG uses a different composition from the in-app display (macOS reference: `spec/v1.7.1/flächenfüllung-chart-macOS.png`).

```
┌──────────────────────────────────────┐  ← #1E1E1E background, always dark
│  5-STUNDEN-FENSTER                   │  ← 11px Semibold #8E8E93, uppercase
│  49%                     ⏱ 1h 56min │  ← percentage left (28px Semibold #FFF), countdown right (13px #8E8E93)

│ │  [area chart — same colors       │ │  ← chart area, #2C2C2E background, 8px radius

└──────────────────────────────────────┘
```

| Property | Value |
|----------|-------|
| Canvas size (logical) | 328px × 240px |
| Canvas DPI | 192 DPI (2x — produces 656×480 physical pixels) |
| Background | `#1E1E1E` (always dark, EXPT-01) |
| Section label top margin | 12px from top |
| Percentage + countdown row top margin | 8px below section label |
| Chart area top margin | 8px below percentage row |
| Chart area height | 120px (matches in-app chart height from styleguide §7.1) |
| Chart area horizontal padding | 8px left and right (matches in-app chart Innenabstand) |
| CCINFO watermark bottom margin | 8px from bottom, 8px from right edge |
| Chart colors | Dark-mode zone colors: green `#30D158`, yellow `#FFD60A`, orange `#FF9F0A`, red `#FF453A` |
| Chart fill opacity | 40% (matches in-app chart fill opacity) |
| Chart line width | 2px (matches in-app chart line width) |
| Glow indicator | 8px circle + 16px glow at 30% opacity (matches in-app) |

## Registry Safety

| Registry | Package | Safety Gate |
|----------|---------|-------------|
| NuGet official | WinUI3Localizer v2.3.0 by AndrewKeepCoding | not required — MIT license, published on nuget.org, no network calls at runtime beyond string file reads |
| NuGet official | Microsoft.Win32.Registry (built-in .NET) | not required — first-party Microsoft, ships with .NET BCL |
| Third-party | none | not applicable |

No shadcn. No web registries. This is a WinUI 3 desktop app — registry safety gate is NuGet-scoped only.

**WinUI3Localizer trust justification:** Package reads `.resw` files from `{exe_dir}/Strings/` at initialization. No outbound network calls. Source is public on GitHub (github.com/AndrewKeepCoding/WinUI3Localizer). Used specifically because native WinUI 3 `ResourceContext.SetGlobalQualifierValue` crashes on Windows 11 in unpackaged apps.
