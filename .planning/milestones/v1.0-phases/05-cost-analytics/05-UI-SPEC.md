### 9.3 Shimmer Loading State

Shown when `IsAggregating = true` (during Heute/Woche/Monat cross-session aggregation). Session tab never shows shimmer.

| Property | Value |
|----------|-------|
| Shimmer element | `Border`, same height as TextBlock (13px), width 60px, corner radius 4px |
| Alignment | Right-aligned (replaces value TextBlock in same grid cell) |
| Animation | `ColorAnimation` from `ShimmerBaseBrush` (`#38383A`) to `ShimmerHighlightBrush` (`#555558`) |
| Duration | 0.8s |
| Behavior | `AutoReverse = true`, `RepeatBehavior = Forever` |
| Visibility toggle | `BoolToVisibilityConverter` on `ViewModel.IsAggregating` — Shimmer visible when true, TextBlock visible when false |
| Layout behavior | Shimmer occupies same grid cell as value — no layout jump |

## Interaction Contract

### Tab Switching

1. User taps a tab → `SelectedTabIndex` updates on ViewModel via TwoWay binding.
2. ViewModel sets `IsAggregating = true` (except Session tab).
3. Shimmer borders become visible; value TextBlocks hidden.
4. Background `Task` runs `GetStatistics(timePeriod)` on thread pool.
5. On completion, ViewModel updates all statistics properties via `DispatcherQueue.TryEnqueue()`.
6. `IsAggregating = false` → shimmer hides, values show.

Session tab: step 2-6 skipped — data already in cache, renders immediately.

### Cost Display Rules

- `costUSD > 0` in JSONL entry → use directly, no tilde.
- `costUSD` null or 0 AND model found in pricing DB → compute via token * price, no tilde.
- Model not found in pricing DB → compute best-effort or show 0, always tilde-prefix.
- Tilde is displayed as a character preceding the dollar sign: "~$4.23"

### Burn Rate Display

- Calculated over rolling 60-minute window.
- Format: integer tokens/hour with "T/h" suffix (e.g. "12.450 T/h").
- If no entries in window or total tokens = 0 → show "0 T/h".
