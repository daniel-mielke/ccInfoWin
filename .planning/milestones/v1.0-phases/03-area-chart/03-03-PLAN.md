**Problem:** When a zone segment has only 1 point (startIndex == endIndex), `DrawChartFills` creates a zero-width closed path (vertical line from plotHeight up to y and back) which is invisible. `DrawChartTopLine`'s inner loop `for (i = startIndex + 1; i <= endIndex)` never executes, producing a degenerate open figure with a single point (invisible). Additionally, the rightmost data point is never extended to the current time position, so the chart has no visible plateau at the end.

**Add helper to ChartRenderer -- `GetRightEdgeAbsoluteX`:**

This method returns a **canvas-absolute** X coordinate (i.e., it includes `LeftMargin` internally). This matches how all other X coordinates are computed in `DrawChartFills` and `DrawChartTopLine` (`ChartRenderer.LeftMargin + ChartRenderer.ToX(...)`), so call sites can use the return value directly without adding `LeftMargin`.

```csharp
public static float GetRightEdgeAbsoluteX(
    IReadOnlyList<UsageHistoryPoint> points,
    int endIndex,
    DateTimeOffset windowStart,
    float plotWidth)
{
    if (endIndex < points.Count - 1)
    {
        return LeftMargin + ToX(points[endIndex + 1].Timestamp, windowStart, plotWidth);
    }
    var nowX = ToX(DateTimeOffset.UtcNow, windowStart, plotWidth);
    return LeftMargin + Math.Min(nowX, plotWidth);
}
```

**Fix in `InitializeAsync` (find the history loading block where `_historyService.LoadHistory()` is called):**

Replace the current history loading block with:

```csharp
// Load persisted history for instant chart display before first poll
var history = _historyService.LoadHistory();

// Check if persisted history is from an expired window
if (history.ResetsAt.HasValue && history.ResetsAt.Value < DateTimeOffset.UtcNow)
{
    // Window expired -- clear stale data so chart starts empty
    _historyService.ClearHistory();
    history = new UsageHistory();
}

if (history.Points.Count > 0)
{
    UsageHistoryPoints = history.Points.AsReadOnly();
    if (history.ResetsAt.HasValue)
    {
        _fiveHourResetsAt = history.ResetsAt;
    }
    ChartInvalidateCallback?.Invoke();
}
```

Key changes:
1. **Stale check**: If `history.ResetsAt` is in the past, the window has expired. Clear disk data and use empty history. The first poll will start a fresh window.
2. **Set `_fiveHourResetsAt` BEFORE calling `ChartInvalidateCallback`**: This ensures `FiveHourWindowStart` is non-null when the draw handler runs, so the chart actually renders.
3. **Only invalidate if there are points**: No need to redraw an empty chart.

Also in `AppendHistoryPoint` (find the method by name): after a window reset is detected and `history` is replaced with `new UsageHistory()`, also update `_fiveHourResetsAt` to `apiResetsAt` BEFORE setting `UsageHistoryPoints`. This ensures the draw handler has the correct window start. The current code sets `_fiveHourResetsAt` after `AppendHistoryPoint` returns (in `UpdateUsageProperties`), but the chart invalidation inside `AppendHistoryPoint` fires before that assignment. Move the `_fiveHourResetsAt = apiResetsAt` assignment into `AppendHistoryPoint` before `ChartInvalidateCallback`:

```csharp
private void AppendHistoryPoint(DateTimeOffset? apiResetsAt, double utilization)
{
    var history = _historyService.LoadHistory();

    var windowResetDetected = history.ResetsAt.HasValue
        && apiResetsAt.HasValue
        && history.ResetsAt.Value != apiResetsAt.Value;

    if (windowResetDetected)
    {
        history = new UsageHistory();
    }

    history.ResetsAt = apiResetsAt;
    history.Points.Add(new UsageHistoryPoint
    {
        Timestamp = DateTimeOffset.UtcNow,
        Utilization = utilization
    });

    _historyService.SaveHistory(history);

    // Set window timestamp BEFORE invalidating chart so FiveHourWindowStart is non-null
    _fiveHourResetsAt = apiResetsAt;
    UsageHistoryPoints = history.Points.AsReadOnly();
    ChartInvalidateCallback?.Invoke();
}
```
