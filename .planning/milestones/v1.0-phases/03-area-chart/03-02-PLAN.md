    public static class ChartRenderer
    {
        public const float LeftMargin = 22f;
        public const float BottomMargin = 16f;
        public const double WindowDurationSeconds = 5 * 60 * 60;

        public static float ToX(DateTimeOffset timestamp, DateTimeOffset windowStart, float plotWidth)
        public static float ToY(double utilization, float plotHeight)

    - `ToX`: `(float)((timestamp - windowStart).TotalSeconds / WindowDurationSeconds * plotWidth)`. Clamp to [0, plotWidth].

    - `public static Windows.UI.Color GetColor(string brushKey, bool isDark)` -- returns from lookup, fallback to Colors.Gray.
    - `public static Windows.UI.Color GetZoneColor(double utilization, bool isDark)` -- combines ColorThresholds.GetThresholdKey + GetColor.

    5. **Reset detection + append in UpdateUsageProperties**: After the existing `_fiveHourResetsAt = data.FiveHour.ResetsAt;` line, add:
       ```csharp
       // Reset detection: if resets_at changed, clear history
       var history = _historyService.LoadHistory();
       if (history.ResetsAt.HasValue && data.FiveHour.ResetsAt.HasValue
           && history.ResetsAt.Value != data.FiveHour.ResetsAt.Value)
       {
           history = new UsageHistory();
       }

       // Append new data point
       history.ResetsAt = data.FiveHour.ResetsAt;
       history.Points.Add(new UsageHistoryPoint
       {
           Timestamp = DateTimeOffset.UtcNow,
           Utilization = data.FiveHour.NormalizedUtilization
       });

       _historyService.SaveHistory(history);
       UsageHistoryPoints = history.Points.AsReadOnly();
       ChartInvalidateCallback?.Invoke();
       ```

    6. **Handle null FiveHour data**: In the `else` branch (when `data.FiveHour == null`), do NOT clear history -- just skip appending. The chart continues to show last known data.

    7. **Clear history on logout**: In the `Logout()` method, add `_historyService.ClearHistory();` before navigating to login.

    **Key behavior decisions:**
    - Reset detection compares stored `ResetsAt` vs API `ResetsAt` -- when they differ, history is cleared and fresh data starts
    - `ChartInvalidateCallback` is called on UI thread (PollUsageAsync runs via DispatcherQueueTimer, already on UI thread)
    - History is loaded once at init, then maintained in-memory with saves after each poll
