    - JsonlEntry tolerates unknown JSON fields without throwing
    - JsonlEntry tolerates missing fields (all nullable except IsSidechain which defaults false)
    - SessionInfo.IsActive returns true when LastActivity is within threshold of now
    - ContextWindowData.Utilization computes TotalTokens / MaxTokens clamped to 0.0-1.0+
    - ContextWindowData holds a list of SubagentContextData (same shape: TotalTokens, MaxTokens, ModelName, AgentId)
    - TokenSummary holds InputTokens and OutputTokens as longs
    - JsonlCache holds Dictionary of filePath -> FilePositionMarker (LastReadPosition, FileSize, LastWriteTime)
  </behavior>
  <action>
    Create the following models in CCInfoWindows/CCInfoWindows/Models/:

    **JsonlEntry.cs**: Records for JSONL deserialization. Use `[JsonPropertyName]` on all fields. All fields nullable except `IsSidechain` (default false). Nested records: `JsonlMessage` (Model, Usage), `JsonlUsage` (InputTokens, OutputTokens, CacheReadInputTokens, CacheCreationInputTokens). Add static `JsonSerializerOptions` field with `PropertyNameCaseInsensitive = true` for reuse.

    **SessionInfo.cs**: Class with properties: `Id` (string, session GUID from filename), `Cwd` (string, working directory), `DisplayName` (string, last path segment), `LastActivity` (DateTimeOffset), `ModelName` (string?, last used model), `IsActive(TimeSpan threshold)` method returning bool. Override `ToString()` for ComboBox display.

    **ContextWindowData.cs**: Record with `TotalTokens` (long), `MaxTokens` (long), `ModelName` (string?), computed `Utilization` (double, TotalTokens/MaxTokens), `ShouldWarnAutocompact` (bool), list of `SubagentContextData` records. `SubagentContextData` has same token fields plus `AgentId` (string).

    **TokenSummary.cs**: Record with `InputTokens` (long), `OutputTokens` (long). Static `Empty` property.

    **JsonlCache.cs**: Class with `Dictionary<string, FilePositionMarker> FilePositions`. `FilePositionMarker` record with `LastReadPosition` (long), `FileSize` (long), `LastWriteTime` (DateTimeOffset). Includes `CachedSessionData` with per-session token sums and context data. JSON serializable for persistence to `jsonl-cache.json`.

    **IJsonlService.cs** in Services/Interfaces/: Interface with:
    - `IReadOnlyList<SessionInfo> Sessions { get; }` — observable session list
    - `ContextWindowData GetContextWindow(string sessionId)` — context for a session
    - `ContextWindowData GetSubagentContext(string sessionId, string agentId)` — single subagent
    - `TokenSummary GetTokenSummary(string sessionId)` — aggregated tokens
    - `Task InitializeAsync()` — start watching + initial scan
    - `void Stop()` — stop watcher
    - `event EventHandler? DataUpdated` — raised when any JSONL data changes
    - `bool IsScanning { get; }` — true during initial scan

    **Messages**: `SessionSelectedMessage` wrapping string? sessionId, `JsonlDataUpdatedMessage` wrapping string sessionId. Both follow existing `ValueChangedMessage<T>` pattern from CommunityToolkit.Mvvm.
