  <action>
    Add `IJsonlService` to MainViewModel constructor injection.

    **New observable properties** (all using `[ObservableProperty]` field pattern):

    Session management:
    - `_sessions` (ObservableCollection&lt;SessionInfo&gt;) — bound to ComboBox ItemsSource
    - `_selectedSession` (SessionInfo?) — bound to ComboBox SelectedItem. On change: update context window + token displays from cache. Persist session ID to AppSettings.LastSelectedSessionId.
    - `_isJsonlScanning` (bool) — shows "Sitzungen werden gesucht..." indicator
    - `_hasActiveSessions` (bool) — false when no sessions at all

    Context window:
    - `_contextUtilization` (double, 0.0-1.0) — for color converter
    - `_contextPercentage` (double, 0-100) — for ProgressBar
    - `_contextPercentageText` (string, default "--") — e.g. "72%"
    - `_contextModelBadge` (string, default "") — e.g. "Opus 4.6"
    - `_showAutocompactWarning` (bool) — orange warning visibility
    - `_hasActiveSession` (bool) — false = show "Keine aktive Session" state
    - `_subagentContexts` (ObservableCollection&lt;SubagentDisplayData&gt;) — for ItemsRepeater
    - `SubagentDisplayData` — internal class with Utilization, Percentage, PercentageText, ModelBadge, AgentId properties

    Token counters:
    - `_inputTokensText` (string, default "--") — formatted with TokenFormatter
    - `_outputTokensText` (string, default "--") — formatted with TokenFormatter

    **OnSelectedSessionChanged partial method** (generated by source gen):
    - If null: set all context/token properties to empty/default state, set `_hasActiveSession = false`
    - If not null: call `UpdateSessionData(value)`, persist to settings

    **UpdateSessionData(SessionInfo session)**: Private method.
    - `var context = _jsonlService.GetContextWindow(session.Id)` — get context data
    - Set ContextUtilization, ContextPercentage, ContextPercentageText from context.Utilization
    - Set ContextModelBadge from `ModelContextLimits.GetDisplayName(context.ModelName)`
    - Set ShowAutocompactWarning from context.ShouldWarnAutocompact
    - Build SubagentContexts from context.Subagents
    - `var tokens = _jsonlService.GetTokenSummary(session.Id)` — get token data
    - Set InputTokensText = `TokenFormatter.FormatTokenCount(tokens.InputTokens)`
    - Set OutputTokensText = `TokenFormatter.FormatTokenCount(tokens.OutputTokens)`
    - Set HasActiveSession = true

    **JSONL service integration**:
    - In `InitializePolling()` or equivalent startup method: call `_jsonlService.InitializeAsync()` (fire-and-forget is OK here since it's a background scan, but wrap in try/catch)
    - Subscribe to `_jsonlService.DataUpdated`: on event, use `DispatcherQueue.TryEnqueue()` to refresh session list and update selected session data
    - On DataUpdated: rebuild Sessions collection. If SelectedSession was previously set, try to re-select by ID (SESS-04: don't auto-switch away). If SelectedSession was null, try restoring from `AppSettings.LastSelectedSessionId`. If that doesn't exist, select first active session.

    **Session grouping logic** for the ComboBox:
    - The ComboBox will use `CollectionViewSource` with grouping. Provide a `GroupedSessions` property that returns sessions grouped by IsActive status. Group key: "Aktiv" for active, "Inaktiv" for inactive. Use the threshold from `_settingsService.LoadSettings().SessionActivityThresholdMinutes`.

    **IMPORTANT — No auto-switching (SESS-04)**: When DataUpdated fires and the currently selected session becomes inactive, do NOT change the selection. Only auto-select when SelectedSession is null.

    **IMPORTANT — No flickering (SESS-03)**: UpdateSessionData reads from cache (synchronous). No loading indicators for session switching — data is always available instantly.
