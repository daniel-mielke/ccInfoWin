    1. Create ViewModels/MainViewModel.cs:
       - Inherits ObservableObject, implements IRecipient&lt;AuthStateChangedMessage&gt;
       - Dependencies: ICredentialService, INavigationService
       - [ObservableProperty] bool IsSessionExpired (controls InfoBar visibility)
       - [ObservableProperty] string StatusMessage (e.g., "Session expired")
       - ValidateTokenAsync():
         a. Get token from CredentialService.GetSessionToken()
         b. If null, return false (no stored token)
         c. Make GET request to https://claude.ai/api/organizations with sessionKey cookie
         d. Use HttpClient (singleton, injected or static)
         e. If 2xx response: return true (token valid)
         f. If 401/403: return false (token expired)
         g. If network error: return true (assume valid, user might be offline -- don't block)
       - [RelayCommand] LogoutAsync():
         a. CredentialService.ClearCredentials()
         b. Clear WebView2 cookies: need to access WebView2's CoreWebView2.CookieManager -- send message or use a shared reference to clear claude.ai cookies
         c. Send AuthStateChangedMessage(false)
         d. NavigateTo&lt;LoginView&gt;()
         e. Reset IsSessionExpired = false
       - [RelayCommand] ReLoginCommand():
         a. NavigateTo&lt;LoginView&gt;()
         b. Reset IsSessionExpired = false
       - Receive(AuthStateChangedMessage):
         a. If message indicates 401 expiry: set IsSessionExpired = true, StatusMessage = "Session expired"

    2. Create Views/MainView.xaml:
       - InfoBar at top: Severity="Warning", Title="Session Expired", Message="Your session has expired.",
         IsOpen bound to IsSessionExpired, with a "Re-Login" Button (Command=ReLoginCommand)
         Per locked decision: non-invasive banner, NOT forced redirect
       - Placeholder content: centered TextBlock "ccInfo Windows" and "Logged in successfully" (Phase 2 replaces this with dashboard)
       - Logout Button: bottom of page, Command=LogoutCommand
       - Keep layout simple -- this is a placeholder that Phase 2 will replace entirely

    3. Create Views/MainView.xaml.cs (minimal code-behind):
       - Resolve MainViewModel from DI
       - Set DataContext
       - Register with WeakReferenceMessenger in Loaded

    4. Modify App.xaml.cs startup flow:
       - After MainWindow.Activate(), add startup routing:
         a. Get ICredentialService from DI
         b. Get INavigationService from DI
         c. Check if token exists: credentialService.GetSessionToken()
         d. If token exists: validate async via MainViewModel.ValidateTokenAsync()
         e. If valid: NavigateTo&lt;MainView&gt;()
         f. If invalid or no token: NavigateTo&lt;LoginView&gt;()
       - Register HttpClient as singleton in DI (for token validation requests)

    5. Ensure NO telemetry code exists anywhere (SECU-03):
       - No analytics NuGet packages
       - No tracking endpoints
       - HttpClient only communicates with claude.ai for token validation

    IMPORTANT per locked decision:
    - Token expiry = InfoBar banner with Re-Login button (NOT forced redirect)
    - Logout clears BOTH Credential Manager AND WebView2 cookies
    - Offline startup with stored token = assume valid (don't block user)
