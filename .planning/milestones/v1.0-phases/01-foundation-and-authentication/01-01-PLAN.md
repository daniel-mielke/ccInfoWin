    1. Create Models/AppSettings.cs:
       - WindowState record/class: X, Y, Width, Height (int)
       - AppSettings class with WindowState property (nullable)
       - JSON-serializable with System.Text.Json

    2. Create service interfaces in Services/Interfaces/:
       - INavigationService: Initialize(Frame), NavigateTo&lt;TPage&gt;(), GoBack(), CanGoBack
       - ISettingsService: LoadSettings(), SaveSettings(AppSettings), LoadWindowState(), SaveWindowState(WindowState)
       - ICredentialService: SaveSessionToken(string), GetSessionToken(): string?, ClearCredentials()

    3. Create Services/NavigationService.cs:
       - Implements INavigationService
       - Wraps WinUI 3 Frame control (pattern from 01-RESEARCH.md)
       - Initialize receives Frame reference from MainWindow after creation

    4. Create Services/SettingsService.cs:
       - Implements ISettingsService
       - Reads/writes settings.json in %LOCALAPPDATA%\CCInfoWindows\
       - Uses System.Text.Json for serialization
       - Creates directory if not exists
       - Handles missing/corrupt file gracefully (return defaults)

    5. Create Helpers/WindowHelper.cs:
       - IsPositionOnScreen(WindowState): bool -- validates saved position against available display areas using DisplayArea.GetFromPoint
       - GetDefaultWindowSize(): SizeInt32 -- returns 360x900

    6. Create Converters/BoolToVisibilityConverter.cs:
       - Standard IValueConverter for bool to Visibility mapping

    7. Rewrite App.xaml.cs with DI container (pattern from 01-RESEARCH.md):
       - Static IServiceProvider Services property
       - ConfigureServices() registers: ISettingsService (singleton), ICredentialService (singleton), INavigationService (singleton), ViewModels (transient)
       - OnLaunched creates MainWindow and activates

    8. Rewrite MainWindow.xaml:
       - Content is a single Frame (x:Name="RootFrame") filling the entire window
       - No custom title bar (standard Windows title bar per locked decision)

    9. Rewrite MainWindow.xaml.cs:
       - Set initial size 360x900 via AppWindow.Resize
       - Create OverlappedPresenter with PreferredMinimumWidth=300, PreferredMinimumHeight=500
       - Restore saved window position/size from SettingsService (validate with WindowHelper.IsPositionOnScreen)
       - Initialize NavigationService with RootFrame
       - Save window position/size on AppWindow.Closing event
       - WebView2 User Data Folder path constant: %LOCALAPPDATA%\CCInfoWindows\WebView2 (used by Plan 02)
