# Requirements: ccInfoWin v1.3

**Defined:** 2026-04-13
**Core Value:** Developers can see their Claude usage limits at a glance in real-time, preventing unexpected throttling during active coding sessions.

## v1.3 Requirements

Requirements for macOS v1.10.0 feature parity. Each maps to roadmap phases.

### Burn Rate Warning

- [x] **BURN-01**: User sees a red warning banner with flame icon when token usage rate projects exhaustion before the 5-hour window resets
- [x] **BURN-02**: Warning banner shows localized time-until-limit in compact format (~Xh YYmin / ~Xmin)
- [x] **BURN-03**: Warning banner disappears when usage rate drops, window resets, or slope reverses
- [x] **BURN-04**: User receives a Windows toast notification (one-shot) when burn rate warning first triggers
- [x] **BURN-05**: Toast notification does not re-fire until warning clears and re-triggers in a new cycle
- [x] **BURN-06**: Burn rate prediction uses linear regression over last 15 minutes with minimum 20% utilization and 3 data points
- [x] **BURN-07**: All burn rate text (banner, toast, time format) is localized in German and English

### Chart Gradient

- [x] **CHRT-01**: User sees a smooth horizontal color gradient (green→yellow→orange→red) on the 5-hour area chart instead of flat zone fills
- [x] **CHRT-02**: Area fill renders at 25% opacity with gradient, line stroke at 100% opacity (2.0 px live, 2.5 px export)
- [x] **CHRT-03**: Gradient spans only the data range, not full chart width, with correct gap handling
- [x] **CHRT-04**: Exported PNG chart matches the live chart gradient rendering
- [x] **CHRT-05**: Gradient renders correctly in both dark and light themes without extra desaturation

### Settings Redesign

- [x] **SETT-01**: User sees a Segmented Control with 4 tabs (General, Updates, Account, About) with colored icon badges
- [x] **SETT-02**: General tab contains all existing settings with uniform 40px row height (label left, control right)
- [x] **SETT-03**: Dropdown values use short time notation (30s, 1min, 5min, 15min, 30min, etc.)
- [x] **SETT-04**: Updates tab shows app version, pricing source info, and last pricing fetch timestamp
- [x] **SETT-05**: Account tab shows token status and logout button
- [x] **SETT-06**: About tab shows app name, version, GitHub link, and credits for macOS original
- [x] **SETT-07**: Tab switching is smooth without page reload, all tabs fit within 360px window width
- [x] **SETT-08**: All settings tab labels and content are localized in German and English

### Session Watcher

- [x] **SESW-01**: FileSystemWatcher configuration is verified to catch file-level session metadata changes (NotifyFilter, IncludeSubdirectories)

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Tray icon flame indicator (FEAT-01d) | Requires tray icon infrastructure that doesn't exist — separate initiative |
| Chart gap fix (FEAT-04) | UsageHistoryPoint has no IsGap field — bug cannot occur in ccInfoWin |
| Performance optimizations (FEAT-06) | Only relevant if profiling shows bottlenecks — no evidence of issues |
| @Observable migration | CommunityToolkit.Mvvm [ObservableProperty] already provides equivalent |
| Sparkle gentle reminders | macOS-specific auto-update framework |
| Menu bar flame icon | ccInfoWin has no system tray / menu bar icon |
| NavigationView sidebar for settings | Overkill at 360px width — Segmented Control is better fit |
