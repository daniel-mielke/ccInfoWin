    Then add three methods to ChartColors.cs:

    1. `public static Color[] BuildColorLookup(bool isDark)` — Returns `Color[101]` where each index i represents utilization i%. Uses 4 gradient stops from the existing ColorTable:
       - Position 0.0 (0%): GetColor("ProgressGreenBrush", isDark)
       - Position 0.5 (50%): GetColor("ProgressYellowBrush", isDark)
       - Position 0.75 (75%): GetColor("ProgressOrangeBrush", isDark)
       - Position 0.90 (90%): GetColor("ProgressRedBrush", isDark)
       For each index i, compute t = i / 100.0, find the two surrounding stops, and linearly interpolate R/G/B. Values t > 0.90 clamp to the red stop color. Alpha is always 255 in the lookup (alpha encoding happens later in ChartDrawing).

    2. `private static Color InterpolateColor((double Position, Color Color)[] stops, double t)` — Finds the two stops surrounding t, interpolates between them. Clamps t to [0.0, 1.0]. For t beyond last stop position, returns last stop color.

    3. `private static Color LerpColor(Color a, Color b, double t)` — Linear interpolation per channel: `(byte)(a.Channel + (b.Channel - a.Channel) * t)` for R, G, B. Alpha always 255.

    Run tests again — all must pass (GREEN).

    2. `public static List<(int StartIndex, int EndIndex)> GetContiguousSpans(IReadOnlyList<UsageHistoryPoint> points)` — Since UsageHistoryPoint has no IsGap field, ALL points form a single contiguous span. Return empty list for empty input, otherwise return `[(0, points.Count - 1)]`. Keep the method signature ready for future gap support.

    3. `public static (float Position, Color Color)[] BuildGradientStops(IReadOnlyList<UsageHistoryPoint> points, int startIndex, int endIndex, DateTimeOffset windowStart, float plotWidth, Color[] colorLookup)` — For each point from startIndex to endIndex:
       - Calculate X position: `ToX(points[i].Timestamp, windowStart, plotWidth)`
       - Calculate span-relative position: `(x - spanStartX) / spanWidth` where spanStartX = ToX for startIndex, spanEndX = ToX for endIndex, spanWidth = spanEndX - spanStartX
       - Guard: if spanWidth <= 0, set to 1f (single-point span)
       - Look up color: `colorLookup[(int)Math.Clamp(points[i].Utilization * 100.0, 0, 100)]`
       - Add to result list as `(Math.Clamp(position, 0f, 1f), color)`
       - After loop: ensure first stop has Position=0.0f and last stop has Position=1.0f (clamp boundary stops)
       - Return as array

    IMPORTANT: Return type is `(float Position, Color Color)[]` — plain C# tuples with `Windows.UI.Color`, NOT `CanvasGradientStop[]`. The conversion to CanvasGradientStop happens in ChartDrawing (Plan 02). This preserves ChartRenderer's pure-math contract with zero Win2D dependency.
