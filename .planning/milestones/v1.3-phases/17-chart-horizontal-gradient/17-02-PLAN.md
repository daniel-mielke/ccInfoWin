  <action>
    **Modify DrawChartFills** — Replace the entire zone-segment iteration with span-based gradient rendering:

    1. Call `ChartColors.BuildColorLookup(isDark)` to get `Color[101]` lookup.
    2. Call `ChartRenderer.GetContiguousSpans(points)` to get span list.
    3. For each span `(startIndex, endIndex)`:
       a. Call `ChartRenderer.BuildGradientStops(points, startIndex, endIndex, windowStart, plotWidth, colorLookup)` to get `(float Position, Color Color)[]` tuples.
       b. Convert tuples to TWO `CanvasGradientStop[]` arrays:
          - **Fill stops**: `new CanvasGradientStop { Position = tuple.Position, Color = Color.FromArgb(64, tuple.Color.R, tuple.Color.G, tuple.Color.B) }` — Alpha=64 for 25% opacity fill (per CHRT-02)
          - **Line stops**: `new CanvasGradientStop { Position = tuple.Position, Color = tuple.Color }` — Alpha=255 (already set in lookup) for 100% opacity line
       c. Calculate absolute X coordinates for brush span:
          - `spanStartAbsoluteX = offsetX + ChartRenderer.LeftMargin + ChartRenderer.ToX(points[startIndex].Timestamp, windowStart, plotWidth)`
          - `spanEndAbsoluteX = offsetX + ChartRenderer.GetRightEdgeAbsoluteX(points, endIndex, windowStart, plotWidth)`
          NOTE: StartPoint/EndPoint are in canvas-absolute coordinates including offsetX (critical pitfall #9 from planning context).
       d. Create fill gradient brush:
          ```csharp
          using var fillBrush = new CanvasLinearGradientBrush(
              resourceCreator, fillStops,
              CanvasEdgeBehavior.Clamp, CanvasAlphaMode.Premultiplied);
          fillBrush.StartPoint = new System.Numerics.Vector2(spanStartAbsoluteX, 0f);
          fillBrush.EndPoint = new System.Numerics.Vector2(spanEndAbsoluteX, 0f);
          ```
          CRITICAL: `using` statement per draw cycle — never cache the brush (pitfall #1 from planning context). Use `CanvasAlphaMode.Premultiplied` to prevent desaturation (CHRT-05).
       e. Build the fill path (closed geometry):
          - `BeginFigure(firstX, baselineY)` where firstX is the absolute X of startIndex, baselineY = offsetY + ChartRenderer.ToY(0.0, plotHeight)
          - For each point startIndex to endIndex: step pattern with `AddLine(x, prevY)` then `AddLine(x, y)` (same staircase pattern as existing code)
          - Extend to right edge: `AddLine(rightEdgeX, lastY)` then `AddLine(rightEdgeX, baselineY)`
          - `EndFigure(CanvasFigureLoop.Closed)`
       f. Fill the geometry: `session.FillGeometry(fillGeometry, fillBrush)` — use the ICanvasBrush overload, NOT the Color overload.

    **Modify DrawChartTopLine** — Same span-based approach for the line stroke:

    1. Add optional parameter: `float lineWidth = 2.0f` at the end of the parameter list (after offsetY). Default 2.0f preserves all existing callers (per CHRT-02).
    2. Call `ChartColors.BuildColorLookup(isDark)` and `ChartRenderer.GetContiguousSpans(points)`.
    3. For each span:
       a. Get gradient stops, convert to `CanvasGradientStop[]` with Alpha=255 (full opacity).
       b. Create line gradient brush with same StartPoint/EndPoint pattern as fill.
       c. Build the line path (open geometry):
          - Same staircase path construction as existing code.
          - Extend to right edge: `AddLine(rightEdgeX, lastY)`.
          - `EndFigure(CanvasFigureLoop.Open)`.
       d. Draw the geometry: `session.DrawGeometry(lineGeometry, lineBrush, lineWidth)` — use the new lineWidth parameter instead of hardcoded `2f`.

    **Modify ExportHelper.DrawChartArea** — Pass export line width:

    Change the DrawChartTopLine call to: `ChartDrawing.DrawChartTopLine(session, resourceCreator, points, windowStart.Value, plotWidth, plotHeight, isDark: true, chartLeft, plotOffsetY, lineWidth: 2.5f)` — adds the `lineWidth: 2.5f` named argument for export (per CHRT-02 success criteria: 2.5px export).

    **Add using directive** to ChartDrawing.cs if not present: `using System.Numerics;` for Vector2.

    **Ensure all CanvasLinearGradientBrush and CanvasGeometry instances are in `using` statements** — critical disposal requirement from STATE.md pitfalls.
