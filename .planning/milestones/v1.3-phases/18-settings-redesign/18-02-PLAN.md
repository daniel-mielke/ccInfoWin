    - Row 2 (*): ScrollViewer containing 4 visibility-toggled content panels

    **SECTION 1 — Header (Row 0):**
    Preserve the existing back button + title StackPanel exactly as-is. No changes.

    **SECTION 2 — Segmented Control (Row 1):**
    ```xml
    <controls:Segmented Grid.Row="1"
        HorizontalAlignment="Stretch"
        Margin="0,0,0,12"
        SelectedIndex="{x:Bind ViewModel.SelectedTabIndex, Mode=TwoWay}">
    ```

    Each `SegmentedItem` uses `.Content` as a horizontal StackPanel with badge + text. Do NOT use the `.Icon` property (it only accepts IconElement, not Border).

    **General tab item:**
    - Badge: Border 18x18, CornerRadius=4, Background=`{ThemeResource SettingsBadgeGreenBrush}`
    - FontIcon inside badge: Glyph=`&#xE713;` (Settings gear), FontSize=10, Foreground=White
    - TextBlock: `l:Uids.Uid="SettingsTabGeneral"`, FontSize=12
    - StackPanel: Orientation=Horizontal, Spacing=6, VerticalAlignment=Center

    **Updates tab item:**
    - Badge: Background=`{ThemeResource SettingsBadgeBlueBrush}`
    - FontIcon: Glyph=`&#xE895;` (Sync), FontSize=10, Foreground=White
    - TextBlock: `l:Uids.Uid="SettingsTabUpdates"`

    **Account tab item:**
    - Badge: Background=`{ThemeResource SettingsBadgeRedBrush}`
    - FontIcon: Glyph=`&#xE77B;` (Contact), FontSize=10, Foreground=White
    - TextBlock: `l:Uids.Uid="SettingsTabAccount"`

    **About tab item:**
    - Badge: Background=`{ThemeResource SettingsBadgeOrangeBrush}`
    - FontIcon: Glyph=`&#xE946;` (Info), FontSize=10, Foreground=White
    - TextBlock: `l:Uids.Uid="SettingsTabAbout"`

    **SECTION 3 — Tab Content Panels (Row 2):**

    Wrap all 4 panels in a `ScrollViewer` with `VerticalScrollBarVisibility="Auto"`.

    Each panel is a `StackPanel` with Visibility bound to the corresponding bool via BoolToVisibilityConverter:
    ```xml
    Visibility="{x:Bind ViewModel.IsGeneralTabVisible, Mode=OneWay, Converter={StaticResource BoolToVisibilityConverter}}"
    ```

    **PANEL 1 — General Tab (IsGeneralTabVisible):**

    Card container: Border with CornerRadius=8, Background=`{ThemeResource CardBackgroundFillColorDefaultBrush}`

    Inside the card, a StackPanel with 7 uniform rows. Each row is a Grid with Height=40, Padding="12,0", two columns (Width="*" and Width="Auto"). Between rows, a separator Border (Height=1, Background=`{ThemeResource DividerBrush}`, Margin="12,0").
