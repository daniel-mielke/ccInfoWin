<objective>
Fix footer button tooltips that do not display at runtime despite correct resw entries.

Purpose: WinUI3Localizer `l:Uids.Uid` resolution writes the `ToolTipService.ToolTip` attached property value at runtime, but WinUI 3 does not create the tooltip infrastructure when the property is set purely via Uid injection on an element that never had the attached property in source XAML. The fix is to add explicit `ToolTipService.ToolTip` placeholder attributes directly in XAML so the tooltip infrastructure is created at parse time, then WinUI3Localizer overrides the text at runtime.

Output: Working localized tooltips on all 3 footer buttons (Refresh, Settings, Quit).
</objective>

