# Milestone v1.2: macOS v1.8.3 Feature Parity

**Status:** SHIPPED 2026-04-12
**Phases:** 12-15
**Total Plans:** 5

## Overview

Brought ccInfoWin to feature parity with macOS ccInfo v1.8.3. Four changes: model-based context detection (Opus=1M, Haiku=200K, Sonnet=configurable), Sonnet context window setting (200K/1M picker in Settings), session orphan filtering (hide deleted directories), subagent sort stabilization (alphabetical by agentId), and footer tooltip/accessibility enhancement (localized tooltips + AutomationProperties.Name).

## Phases

**Goal**: Users see correct context window sizes based on the actual model family — 1M for Opus, 200K for Haiku, and model-family-resolved values for all subagents
**Depends on**: Phase 11 (previous milestone complete)
**Plans**: 1 plan

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**
- `ModelFamily` enum nested in `ModelContextLimits` (not standalone)
- `sonnetContextSize` as default parameter (backward compatible, no call site changes needed)
- `ISettingsService` as optional parameter on `JsonlService` (preserves 13+ existing tests)
- UNC path guard before `Directory.Exists` (prevents network hang)
- `SonnetContextChangedMessage` as dedicated message type (not reusing RefreshIntervalChangedMessage)

**Issues Resolved:**
- Incorrect 200K context for all models (Opus was 200K, now correctly 1M)
- Token-count heuristic unreliable for extended context detection
- Orphaned sessions from deleted directories appearing in dropdown
- Subagent context bars jumping order on refresh

**Issues Deferred:**
- Human verification of footer tooltips and screen reader (ACC-01/02/03)
- SonnetContextChangedMessage payload unused at consumer (could be simplified to unit signal)

**Technical Debt Incurred:**
- VALIDATION.md nyquist_compliant flags not updated post-execution (bookkeeping)
- 2 pre-existing ClaudeApiServiceTests failures remain
- 13 pre-existing JsonlServiceTests parameter naming failures remain
