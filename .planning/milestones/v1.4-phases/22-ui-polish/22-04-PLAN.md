<objective>
Close the Phase 22 UAT Test 1 gap: the refresh button stays clickable while a
refresh is in progress. Plan 22-01 wired `[RelayCommand(CanExecute = nameof(CanRefresh))]`
+ `[NotifyCanExecuteChangedFor(nameof(RefreshCommand))]` (D-04 Option A) — the
correct idiomatic CommunityToolkit.Mvvm 8.4 pattern — but in WinUI 3 with
`x:Bind`, `Command.CanExecuteChanged` does not reliably propagate to the bound
Button's `IsEnabled` (build emits MVVMTK0045 warnings recommending C# 13
`partial property` syntax for full WinRT compatibility).

This plan applies the **pragmatic belt-and-suspenders fix** from UAT.missing:

1. Add explicit `IsEnabled="{x:Bind ViewModel.CanRefresh, Mode=OneWay}"` to
   `FooterRefreshButton` in MainView.xaml.
2. Promote `MainViewModel.CanRefresh` from `private` to `public` (x:Bind
   requires public visibility for binding paths).
3. Add `[NotifyPropertyChangedFor(nameof(CanRefresh))]` to the `_isRefreshing`
   field's existing attribute stack so the source generator wires
   `OnIsRefreshingChanged → OnPropertyChanged("CanRefresh")` and the x:Bind
   re-evaluates on every flip.

**This plan does NOT migrate any [ObservableProperty] field to C# 13 partial
property syntax.** That sweeping refactor (UAT.missing Option B) is explicitly
out of scope. D-04 Option A from Plan 22-01 is reinforced, not replaced.

Purpose: visually disable the button so the user cannot click an already-
spinning refresh.
Output: 3 minimal edits across 2 production files + 1 test file.
</objective>

```csharp
// D-02: 250ms anti-flicker floor — manual click only. D-04 Option A: CanExecute auto-disables button while refreshing.
[RelayCommand(CanExecute = nameof(CanRefresh))]
private async Task Refresh()
{
    if (IsRefreshing) return;
    IsRefreshing = true;
    try
    {
        await Task.WhenAll(
            PollUsageCoreAsync(),
            Task.Delay(TimeSpan.FromMilliseconds(MinimumSpinnerDisplayMs))
        );
    }
    finally { IsRefreshing = false; }
}

private bool CanRefresh => !IsRefreshing;
```

    ```csharp
    public void CanRefresh_RaisesPropertyChanged_WhenIsRefreshingFlips()

        var sut = CreateSut();
        var canRefreshChanges = 0;
    ```
