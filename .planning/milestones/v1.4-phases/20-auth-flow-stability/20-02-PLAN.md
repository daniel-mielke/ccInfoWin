## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `WebViewBridge` (Service) → `Receive` (ViewModel) | The `AuthStateChangedMessage` carries a single boolean — no token, cookie, or PII. The ViewModel never reads from the message beyond `.Value`. |
| `Receive` → `INavigationService` | UI-thread-only navigation; assumption A2 (RESEARCH) — WebView2 raises `OnWebMessageReceived` on UI thread, so messenger dispatch reaches `Receive` on UI thread. |
| `Receive(true)` → `RefreshCommand` | Fire-and-forget async invocation. Re-entrancy guarded by `IsRefreshing` flag (existing) — see Pitfall 6 (RESEARCH). Accepted: in-flight poll uses fresh credentials because `_bridge.Initialize` happens BEFORE `AuthStateChangedMessage(true)` is sent (`LoginViewModel.cs:188-190`). |
