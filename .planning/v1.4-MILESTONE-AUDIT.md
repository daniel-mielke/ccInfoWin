## Gap-Closure Trail

Three real bugs surfaced by UAT, all fixed:

1. **Phase 20 Test 4 (cosmetic):** Reload button invisible on cream-white claude.ai login page. Fixed by Plan 20-05: 30×30 Slate-900 pill wrapper + glyph foreground=White. User confirmed visible.

2. **Phase 21 Test 2 (major):** Settings → Abmelden didn't clear `usage-history.json` (D-13 violation). Fixed initially by Plan 21-03 (LogoutRequestedMessage routing through MainViewModel.Logout), then HOTFIXED via revert to direct-call after production testing revealed WeakReferenceMessenger + AddTransient ViewModels = recipient GC. SettingsViewModel now injects IUsageHistoryService directly and calls ClearHistory FIRST. User confirmed Logout works.

3. **Phase 22 Test 1 (minor):** Refresh button stayed clickable during refresh. Fixed by Plan 22-04: CanRefresh promoted to public + explicit IsEnabled x:Bind override on the XAML Button. User confirmed disabled state during refresh.

## Tech Debt and Backlog (deferred to v1.5+)

Cross-phase issues discovered during UAT but explicitly out-of-scope for v1.4:

- **Cold-start session scanning** (`backlog_session_dropdown_recent_sessions.md`) — `IJsonlService` doesn't surface sessions <120min after a fresh app launch until a new tool-call event lands. Blocks visual verification of POLISH-04 inactive tooltip.
- **Multi-account org-id picker** (`backlog_org_id_picker.md`) — `TryMigrateOrgIdAsync` blindly takes `orgs[0]`, breaking users with multiple Anthropic accounts. User had to manually write Smart Commerce UUID into Credential Manager.
- **Pricing service silent failure** (`backlog_pricing_never_loaded.md`) — `_pricingService.EnsurePricesLoadedAsync()` exception swallowed by catch-all; About-tab shows "Never". Blocks visual verification of POLISH-07.
- **Next 5h-window start label** (`backlog_next_window_start_label.md`) — user request for a "Neues Fenster: Mi., 14:30" label below the countdown. New feature, not a bug.
- **WeakReferenceMessenger + AddTransient = pitfall** (`architecture_weakreferencemessenger_with_transient_vms.md`) — architectural lesson learned during the 21-03 hotfix.
